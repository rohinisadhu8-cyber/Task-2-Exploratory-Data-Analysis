# Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis on the Sample Superstore dataset to identify patterns, relationships, outliers, and sales trends.

## Objectives

- Understand the structure of the dataset.
- Calculate summary statistics.
- Analyze relationships between numerical variables.
- Compare sales and profit across product categories.
- Identify potential outliers.
- Examine monthly sales trends.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Analysis Performed

1. Dataset inspection
2. Data cleaning
3. Summary statistics
4. Correlation heatmap
5. Sales distribution histogram
6. Sales by product category
7. Profit by product category
8. Sales outlier detection
9. Monthly sales trend analysis
